The site's only font is Avenir (see the @font-face rules in src/app/globals.css).

Either install Avenir on the computer (macOS has it; on Windows install the
licensed Avenir, Avenir LT Std or Avenir Next fonts), or put the licensed web
font files here with these names (.woff2 preferred; .woff, .otf, .ttf also work):

  Avenir-Light   (weight 300)
  Avenir-Book    (weight 400)
  Avenir-Medium  (weight 500)
  Avenir-Heavy   (weight 800)
  Avenir-Black   (weight 900)
